Название плаката: **Схема функциональной структуры программы**.

## Назначение

Диаграмма показывает функциональную структуру `ext4tool` по уровням: пользователь, прикладные сценарии, системные модули и внешние средства. На ней видно, какие пользовательские функции поддерживает программа, какие модули их реализуют и через какие внешние библиотеки и системные вызовы выполняется работа с ext4-образом.

## Условные обозначения

| Тип блока | Фигура | Где используется |
|---|---|---|
| Внешний участник/система | Скругленный прямоугольник | Пользователь, POSIX, `ncurses`, `libc/locale` |
| Модуль программы | Прямоугольник | `ext4_super`, `ext4_inode`, `metadata_editor` |
| Прикладная функция | Прямоугольник | Просмотр, поиск, редактирование, справка |

## Стрелки

1. `Пользователь -> ext4tool`: запуск программы и выбор режима работы.
2. `Пользователь -> Прикладные сценарии`: выбор действий просмотра, поиска, редактирования и справки.
3. `ext4tool -> main`: передача управления в точку входа.
4. `Прикладные сценарии -> dashboard`: каждая пользовательская функция реализуется через TUI.
5. `main -> dashboard`: запуск интерфейса после открытия образа.
6. `main -> libc/locale`: настройка локали и базовые строковые преобразования.
7. `dashboard -> ncurses`: отрисовка окон, меню и форм ввода.
8. `dashboard -> ext4_super`: просмотр superblock и групп.
9. `dashboard -> ext4_inode`: просмотр inode.
10. `dashboard -> ext4_dir`: просмотр каталогов и поиск.
11. `dashboard -> metadata_editor`: запуск безопасного редактирования.
12. `ext4_super -> ext4_io`: чтение данных образа.
13. `ext4_inode -> ext4_io`: вычисление смещений и чтение/запись inode.
14. `ext4_dir -> ext4_io`: чтение блоков каталогов.
15. `metadata_editor -> ext4_io`: запись изменённых данных.
16. `ext4_io -> Linux/POSIX`: системные вызовы `open`, `pread`, `pwrite`, `fsync`.
17. `Linux/POSIX -> ext4-образ`: доступ к основному образу.
18. `ext4_io -> backup-образ`: создание резервной копии.
19. `util` связан с `ext4_super`, `ext4_inode` и `metadata_editor` как вспомогательный слой преобразования значений.
