# 01 Algorithm Safe Metadata Edit

Файл диаграммы:

- `01_algorithm_safe_metadata_edit.pdf`
- `01_algorithm_safe_metadata_edit.png`
- `01_algorithm_safe_metadata_edit.svg`

Название плаката: **Схема алгоритма безопасного редактирования метаданных**.

## Назначение

Диаграмма показывает основной алгоритм безопасного изменения метаданных ext4-образа. На ней нужно отразить не просто факт записи, а весь защитный сценарий: проверку режима `write`, проверку совместимости ext4, валидацию поля, создание резервной копии, запись, повторное чтение и проверку результата.

## Условные обозначения

| Тип блока | Фигура | Где используется |
|---|---|---|
| Начало/конец | Скругленный прямоугольник | `Начало`, `Конец` |
| Действие | Прямоугольник | Проверка поля, backup, запись |
| Условие | Ромб | Проверка режима, совместимости, backup, результата |
| Ввод/вывод | Параллелограмм | Получение запроса, сообщения об ошибках/успехе |
| Стрелка | Линия со стрелкой | Направление выполнения алгоритма |

## Стрелки

1. `A01 -> B01`.
2. `B01 -> C01`.
3. `C01 -- нет -> C04 -> Z09`.
4. `C01 -- да -> D01`.
5. `D01 -- нет -> D04 -> Z09`.
6. `D01 -- да -> E01`.
7. `E01 -- нет -> E04 -> Z09`.
8. `E01 -- да -> F01`.
9. `F01 -> G01`.
10. `G01 -- нет -> G04 -> Z09`.
11. `G01 -- да -> H07`.
12. `H07 -- super -> I06 -> J06 -> K06 -> L06 -> M08`.
13. `H07 -- inode -> I09 -> J09 -> K09 -> L09 -> M08`.
14. `M08 -- нет -> N04 -> Z09`.
15. `M08 -- да -> N09 -> Z09`.
