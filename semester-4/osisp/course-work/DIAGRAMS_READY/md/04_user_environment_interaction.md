# 04 User Environment Interaction

Файл диаграммы:

- `04_user_environment_interaction.pdf`
- `04_user_environment_interaction.png`
- `04_user_environment_interaction.svg`

Название плаката: **Схема взаимодействия с пользователем и внешней средой**.

## Назначение

Диаграмма показывает программу `ext4tool` как часть внешней среды: пользователь работает через терминал, программа открывает ext4-образ, при записи создаёт резервную копию, а сборка выполняется через `Makefile` и `GCC`.

## Условные обозначения

| Тип блока | Фигура | Где используется |
|---|---|---|
| Пользователь | UML-актер | Человек слева от границы системы |
| Граница системы | Большой прямоугольник | Область `ext4tool` |
| Пользовательский сценарий | Овал | Запуск, просмотр, поиск, редактирование |
| Внешний объект | Прямоугольник или параллелограмм | Терминал, ext4-образ, backup, сборка |
| Связь | Стрелка или линия | Поток команд/данных |
| Include | Пунктир/стрелка | Редактирование включает backup и верификацию |

## Сценарии внутри ext4tool

| Сценарий | Фигура |
|---|---|
| Запуск с параметрами | Овал |
| Просмотр superblock, inode и каталогов | Овал |
| Поиск по пути, inode и имени | Овал |
| Безопасное редактирование | Овал |
| Получение справки | Овал |
| Создание backup и верификация | Овал |

## Внешние объекты

| Объект | Фигура | Назначение |
|---|---|---|
| Пользователь | UML-актер | Запускает программу и выбирает пункты меню |
| Терминал Linux | Скругленный прямоугольник | `stdin/stdout`, ncurses-интерфейс |
| Файл-образ ext4 | Параллелограмм | Основной объект чтения и записи |
| Резервная копия образа | Параллелограмм | Создаётся перед изменением метаданных |
| Makefile и GCC | Скругленный прямоугольник | Сборка программы |

## Стрелки

1. `Пользователь -> Запуск с параметрами`.
2. `Пользователь -> Просмотр superblock, inode и каталогов`.
3. `Пользователь -> Поиск по пути, inode и имени`.
4. `Пользователь -> Безопасное редактирование`.
5. `Пользователь -> Получение справки`.
6. `Безопасное редактирование -> Создание backup и верификация`: связь `include`.
7. `Запуск с параметрами -> Терминал Linux`: ввод команды и вывод сообщений.
8. `Просмотр superblock, inode и каталогов -> Файл-образ ext4`: чтение.
9. `Безопасное редактирование -> Файл-образ ext4`: запись.
10. `Создание backup и верификация -> Резервная копия образа`: создание backup.
11. `Получение справки -> Makefile и GCC`: связь с подготовкой/сборкой проекта в пользовательском сценарии.
